# 🧸 우리 집 하루 · monchhichi-log

율·한의 **주간 스케줄 + 숙제 체크 + 칭찬 스티커·저금통 + 편지함** 웹앱입니다.
`index.html` **한 파일**로 완결되어 있어 주소만 열면 바로 쓸 수 있어요.

- **주소**: https://yulhan-family.github.io/monchhichi-log/
- **태블릿/아이폰**: Safari로 열고 공유 → **홈 화면에 추가** 하면 앱처럼 전체 화면으로 열립니다.

## 가족 실시간 동기화
- 기록은 이 기기 브라우저(localStorage)에 먼저 저장되고, 인터넷이 되면 가족 클라우드(Supabase `family_state`, `id = 'monchhichi_main'`)와 자동으로 맞춰집니다.
- 항목마다 **마지막으로 바뀐 시각**을 비교해 합치므로, 태블릿과 폰에서 동시에 체크·일정 수정·편지 작성을 해도 서로 덮어쓰지 않습니다.
- 화면 오른쪽 위 배지로 연결 상태를 볼 수 있어요: `🟢 실시간 연결됨` / `🟡 오프라인 · 이 기기 저장`
- 지운 항목은 삭제 표시(묘비)로 함께 남겨 다른 기기에서도 지워집니다.
- 탭·선택한 아이·보고 있는 날짜·타이머·날씨는 기기마다 다른 값이라 동기화하지 않습니다.
- 다른 `family-log` 앱의 기록(`id = 'yulhan_main'`)과는 **완전히 분리**되어 있습니다.

## 저장·백업
- 부모 설정 → **내보내기**로 JSON 백업, **가져오기**로 복원할 수 있습니다.

## 참고
- 개인정보(주소·전화번호·이메일·성씨)는 코드와 배포본에 넣지 않았습니다.
- 날씨는 Open-Meteo(성남시 수정구 좌표) 실시간, 미세먼지는 Open-Meteo Air Quality 기준입니다.
